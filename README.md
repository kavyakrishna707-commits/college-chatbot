# College Information Chatbot

A simple college information chatbot developed using Python and Flask. It uses a college PDF dataset to provide answers to user questions.

## Technologies Used

- Python
- Flask
- HTML
- PyPDF

## Project Structure

- `app.py` - Main Flask application
- `college_data.py` - Extracts data from the college PDF
- `data/college-dataset.pdf` - College information dataset
- `templates/index.html` - Chatbot user interface
